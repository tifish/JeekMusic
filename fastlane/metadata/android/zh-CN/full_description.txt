<p>JeekMusic 是一个简洁的本地音乐播放器，围绕你选择的音乐文件夹组织曲库。默认完全离线，不做任何统计或追踪。</p>

<p><b>曲库</b></p>
<ul>
<li>可以添加多个音乐文件夹（包括 SD 卡），在根一级并列浏览</li>
<li>艺术家视图按拼音 A–Z 排列；"A/B"、"A feat. B" 这样的多个艺术家会拆开</li>
<li>没有标签的歌曲从文件名（"艺术家 - 标题.mp3"）推断艺术家和标题</li>
<li>修复中文标签乱码（GBK 被当成 Latin-1 存储）</li>
<li>支持 CUE 整轨：FLAC / WAV 整轨自动拆成单曲</li>
<li>常听的艺术家可以固定到标签栏</li>
</ul>

<p><b>播放</b></p>
<ul>
<li>不损音质：不重采样、不加音效，24 位音源不截断</li>
<li>熄屏时使用低功耗播放（音频 offload）</li>
<li>断点续播；睡眠定时，停止前音量渐弱</li>
<li>播放列表，支持导入导出 m3u</li>
</ul>

<p><b>歌词</b></p>
<ul>
<li>读取同目录 .lrc 和内嵌歌词；同步滚动、双语歌词、按首调整偏移</li>
<li>可选的在线歌词（LRCLIB，默认关闭），获取后保存为歌曲旁边的 .lrc</li>
</ul>

<p><b>智能标签</b></p>
<ul>
<li>在手机本地根据节奏、响度、频谱识别"运动"和"安静"，不上传任何数据</li>
<li>默认只在充电时分析；识别不准时可以手动修正</li>
</ul>

<p>播放列表、固定的标签和设置会自动备份到音乐文件夹中的一个 JSON 文件里，换手机时跟着音乐一起走。</p>
