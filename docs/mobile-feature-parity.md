# 手机端功能补齐

本轮补齐 Android 与 Windows 的六项用户功能，不扩展个人标签学习的训练平台。

## 用户行为

- 搜索原歌名、艺术家、专辑、文件名，同时支持汉字拼音首字母；英文词不抽取首字母。按当前筛选、全局排序后截取前 200 首，艺术家结果上限仍为 20。
- 排序新增专辑、时长、格式，七种方式均可反向，选择及方向重启保留。未知日期、艺术家、专辑和时长排末，缺失的播放列表引用排末；列表和后续列表队列复用同一顺序。未选择排序时仍保留专辑曲序和播放列表手动顺序；仅默认文件名方向允许拖动播放列表。
- 多选的“更多”提供下一首播放、加入队列、加入现有/新建播放列表、修正智能标签、修正演唱语言。打开菜单时捕获当时选中的歌曲及显示顺序，之后过滤刷新不改变操作目标。
- 标签修正面板显示各维当前值/自动或手工来源及混合状态，默认保持不变。明确选值即手工覆盖，即使与自动值相同；恢复自动保留同步清除语义。按“应用”一次事务写入最多 1,000 首，只重算一次；任一目标变化或写入失败整批回滚。取消/Esc/返回不保存草稿。单首共用同一面板，日常纠正仍沿现有审核和学习反馈管线。
- 分析时机增加“仅手动分析”，取消已排队的自动分析；扫描、启动及自动续接均不得重新排自动任务。“立即分析”仍可运行，并沿显式任务续接。默认继续仅充电时。
- 演唱语言与四维标签独立：中文包含 zh/yue，英文为 en，中英混合可同时匹配两项正向；同组互斥、跨组及其他筛选取交集。未知、未识别、过期和纯音乐不匹配任何正负项。目录/艺术家计数、歌曲列表及后续队列共用允许歌曲集合。单首/多选可纠正中、英、中英、其他、纯音乐、未知或恢复自动。

## 本地语种识别

Android 使用系统 MediaExtractor/MediaCodec 解码，复用生产 PCM 下混/重采样与 YAMNet 人声门槛。使用固定 whisper.cpp 提交 `5922450fbce1ed9d1648babd0d5ac4520055b436`，官方源码压缩包 SHA-256 `500bb90af764f2bb7d51fd7917be8b0c3adcf76bd524b656508fdceb6340d945`；CMake 核验并编译 arm64-v8a/x86_64 CPU 库，Debug/Release 同功能。仅针对固定源码增加可取消的语言检测包装，编码和转写均检查取消/截止；Debug 也启用 O2，以免无优化推断触及预算。第三方 MIT 许可随 APK assets 提供。

首次显式确认后下载多语种 Whisper tiny（77,691,713 字节，SHA-256 `be07e048e1e599ad46341c8d2a135645097a538221678b7acdd1b1919c6e1b21`），临时文件核验后原子安装至私有 noBackup 目录。每首最多三个互不重叠的 20 秒片段、两个 CPU 线程、120 秒协作预算；CUE 只处理其逻辑范围。复用桌面置信度/转写支持门槛，无充分证据保留未知；不以合成语音成绩宣称歌唱准确率。取消保留已提交的逐曲结果。未知及低置信度不会被补成负类；不保存转写，不上传音频，不启动播放、不写媒体或学习答案。

Room 8→9 只新增独立 `track_language` 表；现有播放列表、队列、四维纠正等保留。语种按自动/手工双来源保存，文件时间、精度、大小、CUE 范围或时长变化使结果失效。删除曲目级联清理；恢复自动保存手工清除记录。

## 配对兼容与 MCP

在原配对 TLS 用户元数据 `state` 中增加可选 `vocal_languages={version:1,items:{reference:[record]}}`。record 包含 source、state、languages、confidence、updated_at、size、duration_ms、start_ms；每引用最多两个独立来源。接收端验证来源、状态、语言代码和有限置信度，按来源合并较新的记录；恢复自动以 `MANUAL/state=auto` 传播，不用删除记录让旧修正复活。匹配大小、时长（1 秒容差）和 CUE 起点后绑定本地签名，不声称内容等价，不增加文件内容哈希。无本机匹配的引用等待未来正常交换，不新建歌曲。元数据轻量轮询亦交换，不依赖分析向量开关。旧端忽略扩展；旧目录兼容适配器不交换语种，筛选偏好留在本机。

Windows 追加迁移时间戳，原语种结果保留；UI/MCP 共用相同服务。`song_filter`/`singing_language` 描述及 `singing_language status.pairedSync` 同步说明扩展策略；无新工具或写参数，开发版和正式版目录一致。

## 验证

单元回归包括真实 ICU 拼音首字母、七种排序/反向/未知排末、语种正负和混合规则、证据聚合、CUE 边界。设备回归使用隔离 Room/SQLite，覆盖 8→9 迁移保全、批量写入/失败回滚、AUTO 恢复、签名变化失效、较旧同步不复活和级联清理。

`NativeLanguageDeviceTest` 使用明确复制的私有测试模型及合成普通话/英语诊断语音，运行真实系统解码、YAMNet、Whisper 和推断期间取消；不是歌唱有效性测试。首轮无优化 Debug 推断达到预算失败，启用 O2 后重跑，17 项设备测试全部通过，34.289 秒。首轮批量测试夹具提前关闭学习库导致失败，已修正夹具生命周期并重跑通过。Android lint 0 错误，保留既有警告。

最终 Android JVM 128 项通过；API35/x86_64 `emulator-5584` 的 Room/迁移、原生模型及真实 WorkManager 共 18 项再次通过（32.795 秒）。Debug/Release 两种 ABI 构建成功，lint 0 错误、97 项保留警告。Windows Core 118 项通过，App 796 项通过、2 项既有硬件条件跳过；最后语种定向 16 项再通过。正式 NativeAOT 和日常 ReadyToRun 发布成功，两种真实 EXE 的 43 项 MCP 描述/Schema 完全相同，`pairedSync` v1 诊断一致；原 DataGrid IL2104/IL3053 和 Whisper loader IL3000 保留，新 JSON 节点重载不再引入 AOT 动态序列化警告。

`desktop/tools/test-language-exchange.py` 在两种真实 EXE 的全新隔离数据、合成静音及临时 loopback TLS 配对上均通过：`includeFeatures=false` 仍往返语种、手工覆盖、恢复自动清除、旧包重放不复活、大小不匹配不导入。保留生产资源/速率限制，收到 busy 时关闭连接、等待并重新认证；未放宽门槛。首次脚本漏重连导致闲置 TLS 连接关闭，以及过早清理仍占用的夹具，已修正测试生命周期后两种产物重跑全通过。两端数据库交换另由真实 Room 和 SQLite 回归覆盖，不把 TLS 脚本当作 Android UI 验收。

首次推送后桌面 CI 在构建工作流保护测试即失败：旧测试夹具仍返回 41 项工具，真实 EXE 检查仍写 42，而既有演唱语言功能已使目录变为 43。本轮未增加工具；统一更新 SDK/stdio/重启检查及保护测试到已实测的 43 项契约，保留旧数量拒绝和失败清理断言。工作流保护 7 项通过；不将该初次 CI 失败说成通过。

代理实际操作 Android 新客户端并查看截图：`zjl` 搜索周杰伦及两首歌曲；两首批量纠正的取消/应用和默认保持不变；新建两首播放列表并进入核对；批量加入队列和两首下一首播放的实际手动队列；中英混合、非中文排除、清除；专辑、时长、格式及反向排序；仅手动分析；首次下载确认取消；完整单曲生产服务识别后恢复自动，两个与标题相反的诊断样本分别显示“中文 · 自动”和“英文 · 自动”；最终版本实际取消推断并显示已取消；中文+非英文+专辑反向组合结束进程重启后保留，目录仍为匹配的一首。中文 840×1493@420dpi、字体 1.5 下实际滚动检查语种、识别对话框和全部排序；结束时恢复 1080×2400、字体 1.0，Debug 客户端保留中文及合成目录，播放暂停。

Windows 日常客户端先实时 checkpoint 后结束旧进程，发布并启动新版。稳定初始化后核对歌曲、播放/暂停、位置、队列数量/索引、随机/循环、实时设备音量和静音保持。一次日常发布被本轮 `output` 日志锁定，证据迁至 `desktop/artifacts/mobile-feature-parity/` 后依既有流程归档旧目录；另一次被旧客户端占用 DLL，checkpoint 后退出重试成功，未清用户数据或回写历史队列。手机 UI 验收仅用模拟器 Debug 和明确生成的素材，不安装实体手机、不修改用户真实音频。
