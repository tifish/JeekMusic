# 运动识别固定普通（Rules10）

Windows 与 Android 固定采用历史 NORMAL 完整规则：模型 ln(动感/舒缓) ≥3.25，旧声学加权得分 ≥.60；不恢复灵敏度选项。旧 LOOSE/NORMAL/STRICT 设置、同步及枚举输入均规范为 NORMAL，不能覆盖固定策略。

主分支仍使用采样窗口模型得分的中位数。补救分支要求至少两个互不重叠的独立音乐脉冲上下文，每段至少三个连续模型窗口达到3.25；不存在另一套随灵敏度改变的补救比例。低频显著性≥.025、全频≥.05、BPM95–220、速度一致性≤3 BPM保持不变。采样接近阈值、分歧、持续段、支持率和解释使用同一3.25阈值。脉冲本身不能作为运动正例。

Rules9→10，Analyzer仍为6。有效完整缓存重算自动标签，不为公共门槛变化重解码全库、重提取学习向量或重训。手工标注、审核、其他维度、ClassicalTitles与已启用个人模型的优先语义保留。已验证启用的Rules9个人头可继续使用原验证结果；新的候选启用仍需Rules10及完整验证，不把公共门槛变化当作个人训练结果。

MCP解释返回 NORMAL / fixed_normal / rulesVersion10；MOOD_NORMAL为支持率，MOOD_LOOSE为同值弃用别名。Schema继续拒绝可写sensitivity字段。共享用例覆盖阈值两侧、三窗/两窗、一段/两段、独立/重叠脉冲和历史输入；桌面覆盖缓存、旧持久设置、人工与个人模型优先级。
