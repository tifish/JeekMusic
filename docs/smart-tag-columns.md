# 桌面歌曲标签列与快速修正

主歌曲表头右键可以分别显示“运动”“人声”“古典”“安静”。四列默认隐藏，各自保存显示状态、宽度和顺序；旧布局已有列的选择保留，“智能标签”汇总列继续兼容。新列不提供额外排序，显示沿用领域正负值：运动/非运动、人声/纯音乐、古典/非古典、安静/非安静。未分析、失败或该维度没有结果显示中性 `—`，不推断为负例。旧 `MOOD=QUIET` 只解释为非运动，与安静维度无关。

单击标签单元格打开当前维度菜单，显示当前值和自动/手动来源，以及正值、负值、“恢复自动”三种操作。键盘可将焦点移到单元格按钮，按 Enter 或空格打开，再通过菜单方向键/Enter 操作；Esc 或点外关闭不写入。来源同时出现在 tooltip 和无障碍名称中，不在歌名上增加标记。单元格只修改被点击这一首的这个维度，多选不扩大它的范围；不存在本机 Track 的缺失引用禁用，离线的已有 Track 仍沿用纠正服务。标签点击/双击不会播放或换队列，其他列的选择/双击播放、歌名 Ctrl+C 和现有导航保持原行为。

歌曲右键直接展示紧凑四行标签操作区：每行显示该维度当前值/来源，以及正值、负值、“恢复自动”三个并排按钮，不需要展开子菜单。区块标题显示选中数量，作用于菜单打开时捕获的单选或多选；保留一级“修正智能标签…”完整编辑面板与其他既有菜单项。行摘要区分多个值及自动/手动混合。具体值的勾选只代表所有目标已经具有该值的手工覆盖，自动结果即使同值也不冒充人工标注。“恢复自动”的勾选表示全部目标没有手工覆盖；没有分析结果仍是无结果。选项点击后只提交明确选择的维度，不修改其余维度或同步时间戳。等待事务时整块禁用，成功关闭菜单，失败留在原面板提示并允许重试；Esc/点外取消不写。键盘选中该区块后按右/Enter/空格进入按钮，左右或 Tab 切换操作，上下切换维度；边界上下/Tab 可返回其他菜单项，按钮 Enter/空格直接提交。

两种快捷入口与完整面板、MCP `set_smart_tags` 共用 `SmartTagService.Override`：事务写入覆盖、追加纠正前后审核、重算、同步通知。手工选择与自动同值也会写覆盖；恢复自动保留带更新时戳的 null 同步记录。提交后立即排队重建曲库快照，新建 SongRow 使用新标签；筛选会随之移除不匹配行。选项提前捕获 Track 与维度，列表重算、滚动虚拟化及多选变化不会把正在操作的菜单转向另一首。保存失败会提示并保持事务回滚。

这些入口方便日常纠正与数据整理，不启动训练或选样，审核来源仍为 `manual_correction_not_independent_truth`。主列表展示自动值，因此不是盲标或冻结测试界面。研究标注、暴露记录和独立性须另行按[个人偏好方案](workout-personal-preference-plan.md)建立协议。

## MCP

不增加重复写工具或 UI 专用写入接口。`get_track.tagSources`、`explain_analysis` 和 `set_smart_tags` 保持原 Schema 与行为。只读 `get_diagnostics.mainLayout.smartTagColumns` 新增四列的 `tag/dimension/visible/width/order`，`missingValue/sourceDisplay/manualCheckPolicy/cellAction/cellKeyboard/batchAction` 说明显示与交互语义；`quickCorrection.state/dimension/targetCount/busy` 报告最近快捷操作，无歌曲名称。width 为当前实际 DIP 宽度，隐藏列也可报告其已知宽度；持久化仍由正常 UI 快照负责。未创建主窗时沿用 `mainLayout.created=false`，读取不创建窗口。

开发版与正式 NativeAOT 共用完整工具、参数校验和服务。工具描述、英文资源、MCP 文档与实际 EXE 合约回归同步更新。
