# 固定音乐表征审查与新增同艺人对照

本阶段从 `eb7dfd91a2b79eb6567bb4ee60d50a3e71c99a2a` 出发，检验中间表示是否比固定标签头更适合表达用户的运动偏好。**没有获得足以上线的新分类分支，原三首漏判仍未解决。** 新反馈《简单爱》也是生产规则的漏判，没有写成手工 SPORT。

后续用户已补齐所需 G.E.M.邓紫棋正反配对；同协议新增两首、首次配对查询及预先限定的低容量学习验证见[偏好评估](workout-preference-evaluation.md)。下文九首与必要问题保留为前阶段时点记录；不再重复索取同样配对。

## 先固定协议，再读取结果

[冻结协议](../shared/testcases/workout-representation-protocol.json)在第一次推理前写入，原文件 SHA256 为 `9225a88bd2904a3d3910ecf1ea82d4cd372481bd95adec6d3e21c3d763a3712d`。该哈希标识文件原始字节，包括换行；跨平台换行变更会使审查器拒绝旧报告，不能静默混用。没有看到八例结果后重新选择层、权重、特征维度、参考电平、提示词或阈值。

- 仅复用已下载的原作者 **MTT_musicnn**。主表示为200维 `penultimate`；预先指定153维前端 `temporal` 的时间均值作架构诊断；50类 sigmoid 标签向量作相同输入下的几何基线。没有再跑标签 fast/slow 规则或MSD模型。
- 使用原生产前三段中心的三个互不重叠连续30秒上下文。每段固定原始、−6/+6dB、中心−2/+2秒五种条件；越界直接拒绝，不夹紧位置或按标签挑片段。
- 所有条件统一在浮点PCM增益之后归一到RMS=.1，不削波、不搜索电平。沿用原作者16kHz、96mel、187帧、float16→log10前处理。每个30秒得到十个约3秒窗口。
- 每窗表示先L2归一，十窗求均值后再次L2归一。三个架构输出来自同一次推理，没有分别选取有利片段。
- 只计算余弦距离。每个查询都排除本曲**全部**原始及扰动片段，最近邻只能来自其他录音；同一目标录音内等距片段不当成多个邻居。没有训练分类器、选择PCA轴、拟合200维权重、调标量门槛或生产标签。

预先的稳定性检查为：每处扰动相对原片段的余弦位移，小于该原片段到最近异曲原片段距离的一半。邻域检查要求各处最近异曲的反馈标签一致，且扰动不破坏该一致性。这些是审查一个直接相似度方案是否值得继续的证伪条件，**不是已校准的运动分类规则，也不是独立准确率**。即使通过，也必须另外排除身份混杂。

## 原八首结果：稳定并不等于运动可分

八首×三处×五条件，共120个上下文；仍只有八个相互独立的录音单位，而且全部已用于方案选择。原manifest八份录音的文件mtime与生产快照一致。

| 表示 | 全部八曲通过扰动稳定性检查 | 原24个上下文中最近异曲标签一致数 | 周深18个上下文中最近异曲仍同艺人数 |
|---|---|---:|---:|
| 200维 penultimate | 是 | 13 | 16 |
| 153维 temporal | 是 | 12 | 13 |
| 50类标签头 | 否，初醒的一处偏移失败 | 12 | 16 |

不能将这些相关片段的计数当成准确率或检验显著性。200维主表示最大±2秒位移为.01421，153维为.001756；标签头为.01715。主表示不同原上下文间的最大距离却可达.25733，说明轻微偏移稳定不能代替整曲结构一致。±6dB归一后的位移仅浮点舍入量级（≤4.5e−16），这是输入归一化的性质，不能宣传为模型学到了增益不变性。

主表示三个原上下文的最近异曲分别为：

| 查询 | 最近异曲（按原片段顺序） | 对当前反馈的含义 |
|---|---|---|
| 漫漫 SPORT | Lucky / Lucky / 浮光 | 三处均靠近负例，仍没有可用补判依据 |
| 初醒 SPORT | 浮光 / 浮光 / 江湖觅知音 | 仅一处靠近正例 |
| 和光同尘 SPORT | 漫漫 / 江湖觅知音 / 江湖觅知音 | 三处靠近正例，但不能据此单独增加分支 |
| 浮光 NON_SPORT | 初醒 / 初醒 / 漫漫 | 三处均靠近正例，直接相似度会混淆反例 |

因此，中间表示改善了所测的局部稳定性，未证明它比标签头保留了**可安全直接用于运动分类**的区分。也没有证明200维表示绝对不存在可迁移信息；本实验只否决未经外部标注支持的直接邻域方案。

## 随后新增《简单爱》：真实同艺人正反配对

用户在请求跨艺人配对后提供原话：**“简单爱适合运动”**。生产MCP `search_tracks` 只有一个匹配，`get_track`核对为ID1115、周杰伦、专辑《范特西》、271046ms、MP3/44100Hz/双声道。没有推断“原版”或“Live”，也没有补造节奏/情绪理由。`explain_analysis`报告签名匹配、Analyzer6/Rules8、完整、无待重分析、MOOD自动NON_SPORT，四维来源均AUTO。

[反馈记录](../shared/testcases/workout-feedback.json)现在共九首；保留用户原话，明确理由未提供、唯一录音关联方式和新标注来源。《简单爱》SPORT与《东风破》NON_SPORT构成周杰伦同艺人正反对照。它随后参与本次表征判断，保守记为 `used_for_tuning=true, independent=false`，不把它包装成独立泛化成绩。

冻结协议不变，只对这首新录音追加同样15个上下文，60秒预算；原八首表示复用，不重新解码或搜索。合并九首后：

- 200维主表示中，《简单爱》三段最近异曲为**漫漫 / 和光同尘 / 和光同尘**，全部15个原始/扰动上下文均保持正例邻域；《和光》中后段的最近异曲反过来变成《简单爱》。这是跨周杰伦/周深的局部相似证据，不能再说当前所有正例来自同一艺人。
- 153维temporal中，《简单爱》三段最近异曲为**东风破 / 漫漫 / 东风破**，与同艺人反例混淆；其加入也让《东风破》前两段更靠近这个正例。temporal仍不能代表运动感觉。
- 200维的《漫漫》仍三处靠近负例，《初醒》仍仅一处靠近正例，《浮光》仍三处靠近正例。50类标签头的《简单爱》也全靠近正例，不能将这一首当作中间表示胜过标签头的证据。生产新分支仍不成立。

原先五正例同艺人的混杂已有一个实际对照，但还不能排除歌手、语言、编曲和录音制作。没有声部隔离消融或制作条件配对的因果证据；前端叫 `temporal` 也不保证只保留节奏。没有把原粗标集、舞蹈性、arousal或“蓝色降落伞安静”反馈改作运动真值；没有下载或套用语义不匹配的外部标签。

## 交给主对话的必要问题与停止条件

必要问题已交主对话，随后收到上述《简单爱》答案。当前最少还需要：**请从另一位非周深、非周杰伦艺人中，给出一首你认为适合运动、一首不适合运动的具体歌曲及版本；理由能提供则有帮助。** 不重复询问和光拍速，不补问抽象定义，也不要求用户替代理做客户端测试。

这两个答案的用途明确：同艺人正反配对可否继续否决把音色/制作相似度当运动感；跨艺人正例可否支持固定、低容量的偏好校准。结果不允许直接进入手工标签表；若只有同艺人能解释或反例仍混淆，不新增自动SPORT分支。即使配对有利，也仍需按**整首/艺人分组**的后续独立录音验证，不能把同曲片段拆进训练和测试。

目前没有通过身份偏差检查的稳定**分类候选**，所以未根据模型预判挑歌曲让用户盲标，也不为凑齐九例调整表示。剩余标注用于检验是否有必要进入可学习个人偏好这条产品路线，不保证两首即可训练可靠分类器。如果用户不愿提供这类对照，具体产品选择是保留现有保守自动分类并承认漏判；不能把“再换模型”作为已完成成果，也不能擅自添加按身份或标签表工作的规则。
