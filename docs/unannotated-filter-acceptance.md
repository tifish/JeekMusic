# 未标注筛选验收

Windows/Android 沿用同一筛选入口，“已手工标注”与“未标注”互斥；全不选表示全部标注状态。未标注是四维当前有效 MANUAL 值的补集，含缺失、AUTO 和 PERSONAL 结果。训练算法、激活门槛及封存答案来源未改。

## 已验证

- Windows 245 首生成静音独立库的真实 MCP：四维分别覆盖/恢复 AUTO、同自动值覆盖、最后一维撤回、审计不算手工、无分析结果、来源/搜索/标签 AND、跨 200 首分页、筛选持久化重启、旧 onlyManual 参数及冲突拒绝、修改后下一首选择。脚本：`desktop/tools/test-unannotated-mcp.py`。
- Windows 定向测试包含过滤后下一幸存项、打开菜单原目标、模拟同步撤回刷新、旧 MANUAL 设置、未标注设置回读和异常双状态归一化。完整 App 回归 688 通过、2 个真实硬件测试跳过。首次带 RID 的扩展回归因测试辅助程序相对路径及临时文件条件失败，常规构建布局/独立 TEMP 重跑全通过，未把首次失败计作通过。
- Android JVM 单元测试通过；模拟器 `LibraryDaoTest` 9 项通过。新增 245 首内存 Room 夹具验证四维、无分析、当前状态补集、目录/艺人数、AUTO 撤回、组合条件、PERSONAL 来源及持久化/旧人工参数。清理后台反馈任务后注入纯结果夹具，避免异步重算污染测试。
- 真实 Windows 新客户端与 Android debug 客户端仅针对新增入口做最少交互及截图：已手工标注切换未标注、两者互斥、可见文字/选中状态；未改真实标签。截图留在本机 artifacts，不提交用户数据。
