# 标签学习与可信自动启用

设置提供四维标注/可用数量、缺项和进度，以及“开始学习”、续接/取消/重试。日常修改仍在歌曲列表进行；不在设置增加补题或独立验证题。四个维度分别判断，合格维度先启用，其他维度保留公共规则。

开始学习依次检查材料和录音，首次明确确认下载后准备固定公共组件，自动以六首批次复用同一份表示，逐维训练和效果检查，再更新全库。单个工作进程最多两CPU、2 GiB、240秒，进程树受 Windows Job Object 管理；准备最多一小时，整次任务最多六小时。播放时不启动下一批；工作进程以较低优先级运行。每轮全库最多一万首，持久化游标继续；失败不自动循环，崩溃最多自动恢复三次。取消保留已完成的单录音缓存。

训练、开发、封存的角色、数量、阈值、组件隔离、真实答案来源、各类覆盖、精确区间及扰动门槛沿用 [既有协议](personal-tag-learning.md)。自选且已看自动标签的日常反馈仅为有偏训练，不能通过随机分片或复用训练分数充当独立验证。保守元数据分组只允许这个非独立训练分支，不伪称身份已经人工复核。独立材料不足时如实暂停该维启用，继续原有识别；工程完成不要求用户本轮立即补充真值。

Windows 本机固定 Python worker 的结果与本机检查凭据构成信任边界。通过封存检查后，还要检查训练hash、身份/答案修订、数据代际、单维范围、固定表示、有限且正确形状的中心/轴/缩放/权重、阈值、worker/协议/分析/公共规则版本，以及 Python 和生产 C# 分数与离散决定等价。C# 执行低容量头，声音编码仍复用同一冻结CLAP及同一预处理。检查凭据和模型阶段状态在一个SQLite事务中写入；激活元数据和本机模型指针也原子写入。同步来的 enabled 元数据不能建立本机指针。

生产结果有独立缓存，绑定完整录音SHA-256、文件签名和激活模型版本。全库后台更新不改媒体文件、手工覆盖、审核真值、队列、进度或输出音量。未提取、离线、CUE、过短、不支持、弃权或失败均保留公共回退。手工最高；自动 GENRE 的 ClassicalTitles 优先；运动公共规则始终固定宽松，CALMNESS 保持独立。单维修订/撤回/冲突使该维失效，身份或共享隔离污染按相关范围阻断。全量清除删除学习派生数据并传播防复活边界。

Android 通过既有证书绑定的配对服务请求电脑开始/取消、查询进度，并自动同步数据型识别结果。它不执行Python、不接收个人权重或向量。结果必须同时匹配学习代际、准确文件字节、该维标注修订和激活模型版本；没有覆盖的手机歌曲继续原有规则。前台每轮最多六文件/60秒核验，完成绑定可缓存；文件变化或重编码不能沿用旧绑定。离线修正仍保留并优先，跨端撤回/清除在恢复同步后传播。未联网观察到的远端变化不能假装已收到。

验证以生产 MCP、单元、真实SQLite和隔离集成为主。`PersonalHeadTests` 验证阈值、形状、非有限输入、等价与弃权；`PreferenceDeploymentTests` 模拟可信凭据，仅在内存隔离库覆盖激活、拒绝、失效、结果来源和手工优先。`test-personal-preference.py` 验证固定检查的合格/不合格/材料不足路径。`test-tag-learning-client.py` 在新建且明确限定的 artifacts 夹具中，经真实MCP/TLS/worker覆盖准备取消、失败恢复、自动检查、原子启用、全库44首结果、撤回和普通标签不污染；生成标签/向量与模拟独立来源不是分类有效性证据。真实CLAP提取单列记录，不与合成效果分数混淆。Android设备测试使用专属缓存SQLite/Room路径。

本轮具体验收、包版本/提交和生产用户各维状态见交付记录。工程支持自动启用，不意味着用户的四个真实模型已经通过检查。缺少独立真值的维度保持未启用；不会由测试夹具或普通自选标注自动制造这一证据。
