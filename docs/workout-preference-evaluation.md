## 预先限定的学习探针

在新两首推理前另行写入[个人偏好协议](../shared/testcases/workout-preference-protocol.json)，SHA256为 `67ce90b8888facc9273f990f9d16faa024f9508bc4f15ca0ebd6fec186223a43`。它是后续学习探针，不回改原协议中“不训练分类器”的几何审查。只有一个候选，不在十一曲高维空间搜索监督头、超参、层或阈值：

1. 仅主表示，三个原上下文均值后L2，每录音一个训练行；扰动只作留出查询。
2. 每个训练折内重新拟合无监督中心化PCA，固定前两维；仅用训练折的总体标准差缩放（下限1e−6），不利用留出录音拟合变换。
3. 类别平衡的岭最小二乘，目标−1/+1，固定“加权平均平方误差 + 1.0×权重平方和”，截距不惩罚。严格score>0才为SPORT。两维输入、两个监督系数与截距；分数、嵌入和方差比例都不是概率。
4. 首次只用旧九首训练，成对留出新两首；随后按整首、artist+album、整艺人留出。缺专辑为该录音单独组，不猜专辑。当前十一首没有共享artist+album组，故专辑留出**等同整首留出**，不是额外一次独立验证。
5. 不输入艺人、标题、语言、路径/录音哈希或ID；身份字段仅用于分组/审查。训练须有双标签、PCA秩至少二，否则失败为incomplete；未知自动标签不能当真值。每个留出曲固定五条件分别池化三个上下文，不拆片段训练测试。

## 实施决定、停止点与后续边界

按预定否决条件停止该候选，**不增加自动SPORT分支，不做参数搜索，也不再索取相同艺人配对**。生产继续Analyzer6/Rules8/rhythm1；江湖/Zoobi之前的改善保持，漫漫、初醒、和光、简单爱仍漏判；浮光、东风破、Lucky及新增末日继续NON_SPORT。ClassicalTitles强制古典、独立安静维度/旧QUIET兼容、运动三档和手工优先不变。本轮没有公共模型改善，也没有必要让用户选择上线这个失败的个人模型。

最小关键阻断是**固定表征尚不能在艺人变化下安全区分用户正负偏好**，而非缺少这次已回答的两首标签。若继续投入学习路线，下一可检验步骤应是：先取得可合法用于独立训练/验证、含多艺人同艺人正反配对且标注目标确为运动偏好的外部材料，固定一个偏好监督表征，再把今后未用于选择的整艺人录音作为一次前瞻测试。未知自动标签、舞蹈性/arousal代理和这十一首反复交叉验证不能填补它。当前没有这样的已核验训练材料或候选，故不继续下载模型、无限追加标签或伪装产品进展。只有未来证据通过时，才需明确“公共自动模型”与“显式个人偏好”产品语义，再开展转换/部署验证。

没有新增生产功能/特征，故无需重解码、升级缓存、同步Schema或修改28工具MCP集合；研究结果不能导入生产缓存。开发/NativeAOT和Android继续相同生产契约，未加入Python/TF研究依赖。代码与原仓库权重ISC许可沿用前阶段核对，没有新权重获取、转换或分发。Windows CPU研究成本不能作为Android/ARM成本；没有可上线候选，不做无意义的两端全套推理或手机预算承诺。
